# BookMyStay App

A Java console application for hotel room booking, built step by step as a series of use cases.

The current version (Use Case 3) adds central room inventory management: a `RoomInventory` class keeps the number of available single, double and suite rooms in a `HashMap` and supports checking and updating availability.

## Run

Open the project in IntelliJ IDEA and run `HotelBookingApp`, or from the command line:

```bash
cd src
javac HotelBookingApp.java
java HotelBookingApp
```
